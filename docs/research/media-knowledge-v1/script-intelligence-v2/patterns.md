All entries are **GIẢ ĐỊNH / CAN_XAC_MINH**, source `E-REQUEST-V2`, license
`N/A-design-metadata`, owner `Narrative Research`, revalidate `2026-10-20`. They
are candidates, not universal formulas. Metrics and thresholds must be set by

## Global anti-patterns

Unsupported certainty, composite quotations, unlabeled reconstruction, false
balance, straw man, fake scarcity, arbitrary ranking, context stripping,
retention bait, unpayable open loops, causation from sequence, copied
expression, unsafe procedural omission and one-template-for-all-genre are
failures requiring rejection or human review.
